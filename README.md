# 🌍 Global Health Index Analytics Dashboard | Advanced Excel

## 📌 Project Overview

This project analyzes **15,000+ global health records** using **Microsoft Excel** to evaluate health performance across countries and identify relationships between economic and healthcare indicators.

The project demonstrates practical **Data Cleaning, Data Analysis, Data Visualization, Pivot Tables, Slicers, and Dashboard Development** skills.

---

## 🎯 Project Objectives

* Analyze global health performance across countries and years.
* Compare Health Index, Life Expectancy, GDP, Healthcare Expenditure, and Population.
* Identify trends and rankings in global health indicators.
* Analyze the relationship between GDP and Health Index.
* Build an interactive Excel dashboard for data-driven insights.

---

## 📊 Dataset

The dataset contains **15,000+ records** with the following columns:

| Column                 | Description                      |
| ---------------------- | -------------------------------- |
| Country                | Country name                     |
| Year                   | Year of observation              |
| Health_Index           | Overall health performance index |
| Life_Expectancy        | Average life expectancy          |
| GDP_per_Capita         | GDP per capita                   |
| Healthcare_Expenditure | Healthcare expenditure           |
| Population             | Population size                  |

---

## 🧹 Data Cleaning

The following data-cleaning steps were performed:

* Removed duplicate records.
* Identified missing values using Excel functions.
* Standardized numerical formatting.
* Applied comma formatting to Population.
* Formatted Health Index to 2 decimal places.
* Ensured Year values were stored as numbers.

---

## 📈 Analysis & Visualizations

The dashboard includes multiple visualizations:

### 1. Country Health Index Comparison

A **Column Chart** compares the average Health Index across countries.

### 2. Top 10 Countries

A **Bar Chart** highlights the top-performing countries based on Health Index.

### 3. Health Index Trend

A **Line Chart** shows the average Health Index trend across years.

### 4. Population Distribution

A **Pie Chart** visualizes population share by country.

### 5. GDP vs Health Index

A **Scatter Plot** analyzes the relationship between GDP per capita and Health Index.

### 6. Healthcare Spending vs Life Expectancy

A **Stacked Column Chart** compares healthcare expenditure and life expectancy across countries.

### 7. Health Index vs Life Expectancy

A **Combo Chart** provides a dual-axis comparison of Health Index and Life Expectancy.
